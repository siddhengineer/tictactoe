# **App Name**: Retro Game Zone

## Core Features:

- Themed Tic Tac Toe Game: Implement a modern and Pokémon-themed Tic Tac Toe game with a switch to toggle between themes.
- Bottom Navigation Bar: A navigation bar with Home, Play (Tic Tac Toe), Leaderboard, and Settings tabs.
- Leaderboard with Avatars: Leaderboard displaying top scores, win streaks, and Pokémon-themed avatars (using device storage)
- Settings Page: Settings page to toggle sound effects, switch themes, and view app information. Settings stored locally, or migrated to the cloud later.
- Share Score Functionality: Share My Score' button on the leaderboard to share scores via device-native sharing options.

## Style Guidelines:

- Primary color: Vibrant blue (#3498db), reminiscent of classic game interfaces, providing a sense of trust and reliability.
- Background color: Light gray (#ecf0f1), offering a clean and unobtrusive backdrop that keeps the focus on the game.
- Accent color: Energetic orange (#e67e22) to draw attention to interactive elements and CTAs.
- Use the system default sans-serif font for clear readability and a modern feel. In the retro Pokémon theme, switch to a pixel-art font.
- Use flat, minimalist icons for the navigation bar and settings, with retro Pokémon-style sprites in the themed game.
- Subtle transitions and animations when switching between themes and on user interactions (e.g., placing X or O).
